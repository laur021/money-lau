# MoneyLau

MoneyLau is a personal finance manager built with Next.js, TypeScript, Tailwind CSS, shadcn/ui, and Supabase.

## Phase 1

This foundation includes the application shell, dark-first theme support, a staged login page, public environment validation, and Supabase client scaffolding. Authentication and financial records are intentionally deferred to later phases.

## Local Development

1. Copy `.env.example` to `.env.local` and set Supabase values when available.
2. Run `npm run dev`.
3. Validate with `npm run lint`, `npm run typecheck`, `npm test`, and `npm run build`.

Implementation progress lives in `docs/IMPLEMENTATION_STATUS.md`.
